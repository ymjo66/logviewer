윈도우 전용 .exe 실행 가이드

별도의 웹 파일이나 설치 없이 단일 X_Drone_Log_Viewer.exe 실행파일로 작동하며, 인터넷 연결 없이도 모든 분석 기능을 사용할 수 있습니다.

1. X_Drone_Log_Viewer.exe 단일 실행파일 (설치 불필요 · 오프라인 동작)

설치 과정 없이 X_Drone_Log_Viewer.exe를 더블클릭하면 바로 실행됩니다. 차트·폰트 등 필요한 리소스가 모두 실행파일 안에 포함되어 있어 인터넷 연결 없이도 모든 분석 기능이 동작합니다. 바탕화면 아이콘이 필요하면 exe 파일을 우클릭 → 보내기 → 바탕 화면에 바로 가기 만들기를 선택하세요.

2. 로그 파일 여는 방법

상단 .bin / .log 다중 파일 열기 버튼을 누르거나, 파일을 프로그램 창으로 드래그 앤 드롭하세요. 탐색기에서 .bin / .log 파일을 X_Drone_Log_Viewer.exe 아이콘 위로 끌어다 놓으면 실행과 동시에 자동으로 분석됩니다. 텔레메트리 CSV 내보내기 시에는 저장 위치를 선택하는 창이 표시됩니다.

3. 자동 업데이트 (GitHub 릴리즈)

실행할 때마다 GitHub 저장소 릴리즈에서 새 버전을 확인합니다. 새 버전이 있으면 업데이트 내용과 함께 안내 창이 뜨고, 지금 업데이트를 누르면 새 실행파일을 내려받아 자동으로 교체한 뒤 다시 시작합니다. 현재 버전: -
