# 현재 프로그램의 자기장 계산

현재 `magVarPct`는 단순 자기장 변동률이 아니라, 스로틀과 자기장 크기의 상관성을 가중한 자체 추정 지표입니다. 전류(BAT.Curr)는 이 수식에 사용하지 않습니다. 계산식을 이번 작업에서 바꾸지는 않았으며, 화면 설명을 ‘추정’으로 정정했습니다.

## 1. 자기장 크기와 평활화

타임라인 각 시점에서 가장 가까운 MAG 샘플로 `B = sqrt(MagX² + MagY² + MagZ²)`를 계산합니다. MAG에 여러 인스턴스가 있으면 현재 분석은 기본적으로 번호가 가장 작은 인스턴스를 사용합니다.

현재 시점 앞뒤 2개를 포함한 최대 5개 샘플의 평균으로 평활화합니다. 크기가 10 이하인 샘플은 제외합니다. ‘5개 샘플’이므로 5초 평균이라는 뜻은 아닙니다.

## 2. 기준 자기장 B0

시동 시각 이후, 스로틀 35% 미만, 평활화 자기장 크기 50 초과인 샘플들의 중앙값입니다. 조건에 맞는 샘플이 없으면 전체 기록 중 크기 50 초과인 샘플의 중앙값으로 대체합니다. 둘 다 없으면 B0=0입니다.

현재 조건은 시동 해제 이후의 낮은 스로틀 데이터도 포함할 수 있으므로 순수한 지상 무부하 실측값과 같다고 단정할 수 없습니다.

## 3. 단순 변화폭 R

첫 이륙부터 마지막 착륙까지의 평활화 자기장 최솟값·최댓값을 사용합니다.

`R = (Bmax - Bmin) / B0 × 100`

예를 들어 B0=500, Bmin=450, Bmax=550이면 R=20%입니다. 여러 소티가 있으면 현재 구현의 첫 이륙~마지막 착륙 구간에는 소티 사이의 지상 구간도 포함될 수 있습니다.

## 4. 스로틀별 차이 D와 상관계수 r

- 같은 구간에서 스로틀 40% 이하 샘플의 평균 자기장과 58% 이상 샘플의 평균 자기장을 구합니다.
- 각 그룹에 샘플이 3개 이상이면 `D = |고스로틀 평균 - 저스로틀 평균| / B0 × 100`입니다.
- 스로틀과 자기장 크기의 피어슨 상관계수 r은 유효 샘플이 11개 이상이고 양쪽 분산이 충분할 때 계산합니다. 아니면 r=0입니다.
- 저·고스로틀 표본이 부족하되 `|r| >= 0.45`이면 `D = R × |r|`로 대체합니다. 그 외에는 D=0입니다.

## 5. 화면에 사용되는 최종 지표 F

```
|r| >= 0.35 : F = max(D, R × |r| × 0.7)
|r| <  0.35 : F = D × 0.6
```

따라서 R=20%, D=8%, r=0.6이면 화면 지표는 max(8, 20×0.6×0.7)=8.4%입니다. 단순 변화폭 20%와 다른 숫자가 표시되는 이유입니다.

## 해석 범위

이 값은 프로그램 고유의 가중 추정치입니다. 상관성이 낮다는 이유만으로 자기장 간섭이 없다고 단정할 수 없고, 기록이나 유효 표본이 없을 때도 현재 수식은 0을 만들 수 있습니다. 단순 자기장 변동률 R, 이 추정치 F, CompassMot 보정 과정의 실측 간섭률은 서로 구분해야 합니다.

ArduPilot의 CompassMot는 전류 모니터 기반 보정 절차를 설명하고 있습니다: [공식 문서](https://ardupilot.org/copter/docs/common-compass-setup-advanced.html).

이벤트 코드 확인 과정에서 발견한 별도 오류도 수정했습니다. `EV 43/44`는 ACRO 트레이너 이벤트이고, EKF 고도/방위 리셋은 `EV 60/62`입니다: [공식 이벤트 정의](https://github.com/ArduPilot/ardupilot/blob/master/libraries/AP_Logger/AP_Logger.h).
